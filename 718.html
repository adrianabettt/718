Explore, experimente e descubra como os computadores se identificam e conversam na internet.

Endereço IP

Todo computador em rede tem um endereço único. Sem ele, os dados não sabem para onde ir.

🏠 Analogia

Assim como toda casa precisa de um endereço para receber encomendas, todo computador conectado a uma rede precisa de um endereço IP (Internet Protocol) para receber e enviar dados. Sem ele, os pacotes simplesmente não chegam ao destino.

🔢 Montador de Endereço IP

Um endereço IPv4 é formado por 4 números (chamados octetos), separados por pontos. Cada número vai de 0 a 255. Altere os valores abaixo e veja o endereço ser montado:

192.168.1.15
IP local (rede interna)

📶 Tipos de endereço IP

IP Local (Privado)
Funciona só dentro da rede (escola, casa). Exemplos: 192.168.x.x, 10.x.x.x
IP Público
Visível na internet. Cada site tem um IP público. Exemplo: Google usa 8.8.8.8

Simulador de Ping

O comando ping envia pacotes de teste e mede se o destino está respondendo.

Como funciona o ping?

Seu computador envia 4 pequenos pacotes para um endereço IP. Se o destino estiver ativo, ele responde. O tempo de resposta (em ms) mostra a velocidade da conexão.

HTTP

🔓
  • HyperText Transfer Protocol
  • Protocolo de transferência de páginas web
  • Dados viajam sem criptografia
  • Qualquer um no caminho pode "ler" os pacotes
  • ⚠️ Não use para senhas ou dados pessoais

HTTPS

🔒
  • HTTP + Secure (TLS/SSL)
  • Mesmas regras do HTTP, mas com criptografia
  • Os pacotes são "trancados" antes de sair
  • Mesmo interceptado, ninguém consegue ler
  • ✅ Obrigatório para bancos, senhas, compras
